英伟达斥 60 亿美元获 Poolside 授权，再投 10 亿美元并吸纳百余名员工

8/22 据彭博援引知情人士，英伟达已同意向 AI 编程模型初创公司 Poolside 支付 60 亿美元模型许可费，并向其 109 名员工发出入职邀约；同时以 120 亿美元投前估值（不含许可费）追加 10 亿美元战略投资。交易呈「许可费 + 股权投资 + 人才引进」复合结构，Poolside 三位联合创始人留任、公司继续独立运营，现有股东将获一笔派息。Poolside 由 GitHub 前 CTO Jason Warner 等创立，专注代码生成与重构模型（Malibu、Point），2024 年 10 月估值仅 20 亿美元，本轮 120 亿估值约 6 倍跳升。此模式与英伟达此前收购 Groq（约 200 亿许可 + 吸纳员工）如出一辙，已被立法者质疑是在绕过并购反垄断审查。

英伟达的「许可费 + 挖人」组合拳，本质是把「并购」拆成两笔账——技术用钱租、人才用 offer 吸，从而避开反垄断审查的触发线。Poolside 从 20 亿到 120 亿估值的 6 倍跳升，说明在代码智能体赛道上，「模型工厂 + 顶级工程团队」已是稀缺资产。当芯片霸主开始用资本给下游模型公司「输血并控股」，AI 产业链的「算力华尔街」又多了一块拼图。

Anthropic IPO 拟募超 1000 亿美元，估值瞄准 2 万亿美元

8/22 据《纽约时报》援引两名知情人士，Anthropic 承销银行在近期路演中表示，公司可能通过 IPO 募资超 1000 亿美元，估值高达 2 万亿美元。若落地，成立仅 5 年的 Anthropic 将超越 SpaceX 今年 6 月的纪录（估值 1.77 万亿、募资 857 亿），成为史上最大 IPO。财务数据：上个月年化收入超 650 亿美元（去年底为 90 亿），Q2 单季营收 116 亿美元；今年私募轮估值 9000 亿、6 月已提交上市申请，预计未来几周公布招股书。投资者已就「如何维持高价收费」「如何应对开源权重模型兴起」提出质疑。

5 年做到 2 万亿估值的 IPO，Anthropic 正在把「AI 实验室」重新定义成「资本市场现象级标的」。650 亿年化收入 vs 一年前 90 亿，增速固然惊人，但真正被反复拷问的是「溢价能否持续」——当开源模型把价格打下来，Anthropic 靠「更强模型」收溢价的故事还能讲多久。这是 AI 第一波「烧钱换规模」神话走向公开市场定价的关键一跃。

Anthropic 挖来谷歌 TPU 老将 Amir Salek，加速自研芯片

8/22 Anthropic 周五确认，谷歌定制芯片项目创始人 Amir Salek 将加入其算力团队，向 James Bradbury 汇报。Salek 2013-2022 年作为谷歌 TPU 项目创始人兼负责人，主导交付了前七代 TPU；此前在英伟达工作八年，创立并领导 SoC 业务，主导 25 个以上 GPU 与 Tegra 芯片项目。Anthropic 目前从英伟达、谷歌、亚马逊等多方采购芯片，但近期已释放自研信号（官网挂出「组建自研定制芯片团队」招聘），据传已与三星接洽 2nm 制程。竞对 OpenAI 已发布与博通合研的 Jalapeño 芯片，计划年底投入使用。

挖来「TPU 之父」，是 Anthropic 自研芯片战略从「招聘启事」升级为「关键人物落地」的标志。当算力供给成为 AI 竞赛的最大瓶颈，前沿实验室的终局打法高度趋同——自研芯片摆脱对外部供应商的议价与供货依赖。Salek 从谷歌到英伟达再到 Anthropic 的履历，本身就是一部「算力话语权」的转移史，而 Anthropic 正在把「定制芯片」这张牌摆上 IPO 的牌桌。

Claude Security 上线 Mythos 5，另投 3500 万美元 0xDAF 基金

8/21 Anthropic 宣布，此前仅限受信任防御方使用的网络安全模型 Claude Mythos 5，现已在 Claude Security 中为 Enterprise 客户提供漏洞扫描——返回 CWE 分类、严重度、置信度与建议修复补丁，所有补丁需人工审核后落地。同步推出 3500 万美元的 Defender Advantage Fund（0xDAF），以 Claude 额度形式资助开源软件漏洞修复；并预告扩大 Cyber Verification Program。核心理由：风险集中在用户可直接操控模型时，若用户只能收到「补丁 / 告警」这类防御性产物，风险大幅降低，故可安全开放。

Mythos 5 是那个「强到不敢公开发布」的模型，Anthropic 这次的解法很聪明——不开放模型，只开放「防御性产物」：让你拿到漏洞补丁，但不给你能拿去造攻击的直接访问权。这种「受控输出、不开放自由提示」的分发模式，可能成为所有「双用途前沿能力」的通用合规模板。安全能力从「少数玻璃房伙伴」走向「全部企业客户」，本身就是一次对「模型治理」的公开实验。

商汤开源 SenseNova U1.5 Lite：支持超长指令与原生 4K

8/21 商汤正式开源轻量级统一多模态大模型 SenseNova U1.5 Lite（8B 参数），基于 NEO-unify 统一架构与 MOPD 多专家在线策略蒸馏，将文字、美学、编辑等专家能力融合进单一 8B 模型。核心能力：原生支持 3-4k 字符超长指令遵循（多数开源模型 1k 字符以上易崩溃）、强化中英文文字与复杂海报布局、支持 Bounding Box 与多图参考的精细控制、原生 4K 高分辨率输出。已在 GitHub、Hugging Face、魔搭社区开源，可在 SenseNova Studio 在线体验。

Grok Build 全量上线：一句话生成应用，X 内直接试玩

xAI（现 SpaceXAI）宣布 Grok Build 结束早期测试，8/19 起面向所有套餐用户全量开放，覆盖网页、iOS、Android。用户用自然语言描述应用 / 小游戏 / 网站 / 仪表盘，即可在对话界面实时生成并运行完整版本；发布应用获得 grok.me 独立链接，分享到 X 平台时以内联卡片呈现、支持信息流内直接试玩。新版本补齐 Remix（二次分叉改造）、一键导出 GitHub、第三方 API 密钥管理、直连 xAI API（免密钥管理）等能力。Grok Build 7 月 15 日已开源终端 agent harness，与 Anthropic Artifacts、Lovable、v0、Bolt 正面竞争。

openai/codex：Codex Harness 全面开源，107K★

OpenAI 8/19 将驱动 Codex App、CLI、IDE 扩展运行的底层执行框架 Codex Harness 完全开源（Apache-2.0，github.com/openai/codex），开放此前内部维护的 Rust 核心（codex-rs）与 app-server 层。三层集成接口：codex exec（轻量非交互，跑 CI 脚本）、Codex SDK（TypeScript 程序化编排，可切换任意 OpenAI 兼容端点）、codex app-server（持久会话，构建产品级 Agent）。截至 8/21 累计 107,443 Star。官方实测仅优化 Harness 设计，GPT-5.6 Sol 在 ARC-AGI-3 从 13.3% 飙升至 38.3%、Token 输出减少 6 倍。

「Everything through the harness」——模型不直接面向用户，而是被 harness 封装后可控地对外提供能力，这条哲学与 DeepSeek Harness 高度呼应，如今 OpenAI 也把核心执行层交了出来。开源的不是模型，是「智能体如何运转」的底层引擎；当执行框架被标准化、可审计，AI Agent 才能从「黑盒魔法」变成「可嵌进产品的基础设施」。

apache/maka：Apache 首个 local-first Agent 工作台，2.0K★

apache/maka 是进入 Apache 软件基金会孵化的 local-first AI agent workspace，TypeScript 编写、Apache-2.0 协议，约 2.0K★ 且快速攀升。核心设计「Log is the Runtime」：模型消息、工具调用、工具结果、权限决策与终止事件全部写入 append-only 的 Runtime Event Log，会话、UI、上下文与恢复逻辑皆从该日志派生。工具结果裁剪与 LLM compaction 只改变「下一次推理看到什么」，不删除已记录证据。提供 Desktop（Electron+React）、终端 TUI、CLI 三种界面，共用同一 Runtime Host，内置 Read/Write/Edit/Bash/Glob/Grep 工具与粒度权限控制。

Agent 运行时一直散落在个人仓库和创业公司里，Maka 是第一个走进 Apache 那套「养出 Kafka、Spark、Airflow」治理机器的项目。它的赌注是「执行历史是基础设施，不是应用状态」——当模型上下文会「压缩遗忘」，append-only 日志就是黑匣子外的飞行记录仪，让「Agent 为什么这么干」可以被搜索、重放、审计。这或许是 Agent 走向企业级可信的关键一步。

huggingface/OpenEnv：Agentic RL 协议层，2.5K★

huggingface/OpenEnv 是面向智能体强化学习的标准化环境框架，约 2.5K★，已从 Hugging Face 主导项目转为社区治理的「协议层」，由 Meta-PyTorch、NVIDIA、Modal、Prime Intellect、Unsloth 等九家机构联合治理。提供 Gymnasium 风格的 step()/reset()/state() API，配合 Docker 容器化执行与 Hugging Face 上的中心 Hub，当前内置 coding_env、atari_env、OpenSpiel_env、echo_env 四个环境。官方定位：它是「模型、harness、环境、训练器之间的 socket」，不规定奖励函数与训练循环。

前沿实验室为什么能把 Claude Code、Codex 做得顺手？因为模型和 harness 是一起训练、深度耦合的。开源侧做不到这一点，因为「模型 × harness × 环境 × 训练器」是组合爆炸。OpenEnv 的野心是当那个「中立的插座」，把环境标准化从各家自建中解放出来。当 RL 训练环境的「碎片化」被打破，开源 agentic RL 才有可能从「各自为战」走向「可复用、可对比」。
