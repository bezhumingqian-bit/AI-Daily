arXiv · cs.AI · 8月2日 →

CompressAgent：当压缩 Agent 系统提示词，可靠性才是真正的瓶颈

提出 CompressAgent 基准：9 套独立 Agent 控制上下文（ACC）、3 类任务、15,525 次实验／核心发现：75% 压缩率下成功率 92.7%（接近全量 93.8%），但降至 35% 时方法间差距拉大到 27 个百分点（47% vs 20%）／压缩失败主要表现为工具执行和动作解析错误，而非语义理解错误

这篇论文的价值在于把"压缩系统提示词省钱"这个直觉变成了可量化的可靠性曲线。75% 压缩基本不伤性能，但再往下压缩就变成赌命——不同的压缩方法在不同 Agent 上表现出的可靠性完全不一样。这意味着不能一刀切：每个 Agent 需要独立校验自己的压缩安全边界。
