阶跃星辰 Step 5 Preview：600B 参数只激活 27B，开源前三

Grok Voice Transcribe 2.0：词错率砍掉三分之二，登顶排行榜

SpaceXAI 发布 Grok Voice Transcribe 2.0，短语句词错率（WER）从 v1 的 20.6% 降至 6.8%，电话英语通话 WER 从 3.9% 降至 2.7%。覆盖 19 种语言，在 Artificial Analysis 流式语音转文字排行榜 32 个模型中排名第一。定价不变：批量 $0.10/小时、流式 $0.20/小时。API-only，含说话人分离、时间戳和关键词偏置。

MiniMax Code CLI 开源：76.7% 通过率，中位耗时 4 分半

Crusoe 融 39 亿美元：AI 算力基建估值冲破 300 亿

AI 算力基础设施公司 Crusoe 完成 39 亿美元融资，投后估值 309 亿美元。有投资人指出，从未见过基础设施「订单积压」与实际交付收入之间有如此大的鸿沟，信贷市场要求五年确定性，但将面对延期、失败与欺诈。同期，推理芯片初创 Positron 完成 8.75 亿美元 C 轮（估值 50 亿），Manus 据报寻求 5 亿美元融资（估值 40 亿）。

309 亿估值对应一家「还没交付收入」的算力公司——这要么是史上最大的基建泡沫前奏，要么是 AI 版「先修路再收费」的长期主义。投资人的原话很诚实：订单和收入之间的鸿沟「从未见过」。但同一周 Positron（推理芯片）和 Manus（Agent）也在融大钱，说明资本仍在全面押注 AI 基础设施层，而非只赌模型。

TechCrunch · 法庭文件 · 9/19 · 60,202 首录音 · 45 页诉状

UMG/Sony 再诉 Suno v6：6 万首录音、指控「毒树之果」

环球音乐集团（UMG）和索尼音乐在美国马萨诸塞州联邦法院提交 45 页诉状，指控 Suno 新发布的 v6 系列模型是「同一棵毒树之果」——训练于 Suno 早期侵权模型的输出。诉状列出 60,202 首版权录音，称这「仅占被侵权总量的一小部分」。Warner、BMG 和 Believe 已授权内容给 v6，UMG 和 Sony 未授权，正寻求法定赔偿和律师费。

「毒树之果」这个法律概念被搬到 AI 训练领域是标志性事件——如果法院接受「用侵权模型的输出训练新模型 = 继续侵权」这个逻辑链，整个 AI 音乐赛道的「迭代」路径都要重新设计。60,202 首不是小数目，法定赔偿按每首最高 15 万美元算，理论上限接近 90 亿美元。Suno 的 v6 可能是 AI 音乐最后一个「自由训练」版本。

Cloudflare 安全审计 Skill：Agent 写代码时的实时安全门禁

Cloudflare 开源的编码 Agent 安全审计技能，今日全站增速第一（+3,155★，总 16,509★）。不是独立扫描器，而是 Agent 能力插件——Claude Code、Codex 等 Agent 写代码时自动触发多阶段安全审计：静态分析 → 依赖检查 → 逻辑漏洞扫描 → 输出机器可读修复建议。JavaScript 实现，MIT 协议。

这个项目的意义不在技术本身，而在「安全左移」的范式落地：不是写完代码再跑 CI 扫描，而是 Agent 生成的瞬间就拦截。Cloudflare 把自家安全工程经验编码成 Agent 可消费的 skill，等于给 AI 编码加了一层「条件反射」。当 Agent 能力越来越强，「如何引导 Agent 做正确的事」比「如何让 Agent 做事」更值钱。

GitHub · HarnessRouter · 1,522 ★ · UHP 开放标准 · Apache-2.0

HarnessRouter：一个 API 统一 Codex / Claude Code / Hermes 等 Agent 后端

HarnessRouter 开源统一 Agent harness 接口，实现 Unified Harness Protocol（UHP）开放标准，暴露 OpenAI Responses 兼容 API。将 Codex、Claude Code、Hermes、PI、DSH 等现有 harness 变为即插即用的 Agent 后端。支持持久会话、流式输出、文件传输、取消和失败处理。Community Edition 为 Apache-2.0 协议，自托管，Python 实现，1,522★。

Agent 生态正在经历「USB 接口标准化」时刻——每个 harness 都有自己的 API 格式，产品方要接 N 个后端就得写 N 套适配。HarnessRouter 的野心是做 Agent 界的 OpenAI-compatible API：一个接口吃所有。1.5K star 还不大，但 UHP 如果被社区采纳，这个位置的战略价值远超当前热度。GitHub 的 HydraFusion 同期在做类似的事（多模型路由降本 36-67%），说明「harness 层标准化」是本月共识。
